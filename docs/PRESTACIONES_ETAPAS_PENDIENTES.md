# Prestaciones: etapas pendientes

La primera etapa cubre el catalogo y la edicion individual. `precio_base` sigue siendo la unica fuente del precio operativo (mostrado como "Precio del consultorio").

La segunda etapa incorpora importacion manual de CSV, versiones documentales y correspondencias confirmadas. El PDF se conserva como respaldo de revision manual, sin extraccion automatica.

Quedan pendientes: importacion o extraccion desde PDF, actualizaciones porcentuales con vista previa, consulta o extraccion automatica desde la web y automatizacion de nuevas versiones. Ninguna etapa futura debe vincular prestaciones solo por similitud de nombre ni sobrescribir precios personalizados.
