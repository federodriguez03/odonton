# Frontend Odonton (Vanilla JS + Bootstrap)

## Requisitos
- Node.js 18+
- Backend Express ejecutandose en `http://localhost:3000`

## Desarrollo
```bash
npm install
npm run dev
```

Abrir `http://localhost:5173`.

## Configuracion opcional
- `VITE_API_BASE_URL`: base URL para API.
- Si no se define, en desarrollo se usa proxy de Vite (`/api -> http://localhost:3000`).
